# OMEGA: автошкола, Камешково

Готовый сайт записи на вождение. Ставится на телефон как приложение.

## Что в архиве

- `index.html`: весь сайт (вид, логика, настройки).
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: нужны, чтобы сайт ставился на телефон.
- `robots.txt`, `sitemap.xml`: для поиска Яндекса (замените `example.ru` на свой домен).
- `tools/hash_password.py`: помощник для смены пароля.
- `TZ-server.md`: описание серверной части для того, кто её делает.

Все файлы кроме `tools` и `TZ-server.md` кладутся на сервер в одну папку.

## 1. Аккаунт

На сайте один инструктор-владелец.

- Логин: **Низина Елена** (фамилия и имя).
- Пароль хранится в файле не открытым текстом, а в виде `salt` и `hash`.

Других аккаунтов нет. Ученики регистрируются сами, выбирая инструктора.

**Новых инструкторов добавляет только Низина Елена.** Она заходит как «Инструктор», открывает свой профиль (кнопка с её именем), нажимает «Добавить инструктора». Сайт спрашивает «Вы точно хотите добавить инструктора?». После «Да, хочу» она вводит логин нового инструктора (фамилия и имя), его телефон и придумывает ему пароль из 8 цифр. Телефон инструктора видят его ученики на главной странице. Другие инструкторы этой кнопки не видят.

**Машина.** При первом входе каждый инструктор один раз отвечает, какая у него машина. Потом её можно менять только в профиле.

## 2. Как менять настройки

Откройте `index.html` в текстовом редакторе (Блокнот, VS Code). В самом начале скрипта есть блок `CONFIG`:

- `brand`: название (OMEGA).
- `city`: город (Камешково).
- `phone`: телефон автошколы. Он показывается внизу сайта. Пока поле пустое, телефон не показывается. Впишите номер в кавычках, например `'+7 900 000-00-00'`.
- `instructors`: инструктор из настроек (Низина Елена). Здесь можно поменять `name` и `phone`.

**Как поменять пароль Елены:**

1. На компьютере с Python выполните `python3 tools/hash_password.py` и введите новый пароль.
2. Скрипт напечатает строку `salt:'...',hash:'...'`.
3. Вставьте её в `index.html` вместо старых `salt` и `hash`.
4. Загрузите новый `index.html` на сервер.

Логин Елены (`name`) можно поправить, например при опечатке: записи привязаны не к имени, а к внутреннему номеру. Но после смены имени сообщите ей новый логин.

## 3. Как менять тексты на сайте

Любую надпись (заголовки, описания, подписи шагов) можно поменять так:

1. Откройте `index.html` в редакторе и нажмите Ctrl+F.
2. Вставьте в поиск часть нужного текста, например `Индивидуальное вождение`.
3. Замените только слова. Не трогайте символы `<` `>` `'` `"` и обратные кавычки.
4. Сохраните файл, загрузите на сервер и обновите страницу (Ctrl+F5).

Перед правкой сохраните копию файла. После правки откройте сайт и проверьте, что он работает. Если сайт перестал открываться, вы стёрли служебный символ: верните копию.

Основные тексты:

| Что менять | Что искать |
|---|---|
| Подпись над большим названием | `Индивидуальное вождение` |
| Описание на главном экране | `Практика за рулём` |
| Заголовки разделов | `Мои записи`, `Расписание`, `Как это работает`, `Приложение на телефон` |
| Три шага «Как это работает» | `Зарегистрируйтесь`, `Инструктор запишет вас`, `Получите уведомление` |
| Описание сайта для поиска | `<meta name="description"` |

## 4. Как выложить сайт

Нужен адрес с HTTPS. Без него приложение не установится, уведомления не заработают, а вход по паролю не будет работать.

### Вариант А. Свой сервер (Ubuntu)

1. Арендуйте небольшой сервер у российского хостера и купите домен. Направьте домен на IP сервера (запись A).
2. Подключитесь к серверу и поставьте программы: `sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx`
3. Создайте папку: `sudo mkdir -p /var/www/omega`. Загрузите в неё файлы сайта (через программу WinSCP или `scp`).
4. Создайте файл `/etc/nginx/sites-available/omega` (замените `example.ru` на свой домен):

   ```
   server {
       listen 80;
       server_name example.ru;
       root /var/www/omega;
       index index.html;
       location / { try_files $uri /index.html; }
   }
   ```

5. Включите сайт и получите бесплатный сертификат:

   ```
   sudo ln -s /etc/nginx/sites-available/omega /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d example.ru
   ```

6. Откройте `https://ваш-домен` и проверьте сайт.

### Вариант Б. Хостинг в Яндекс Облаке или любой другой

Подойдёт любой статический хостинг (например, Object Storage Яндекс Облака, который раздаёт сайт из папки). Загрузите все файлы сайта в корень и включите HTTPS. Точные кнопки смотрите в справке сервиса.

## 5. Как сделать, чтобы сайт находили в Яндексе

1. Откройте Яндекс Вебмастер (webmaster.yandex.ru) и войдите с аккаунтом Яндекса.
2. Нажмите «Добавить сайт» и введите адрес `https://ваш-домен`.
3. Подтвердите права: Яндекс предложит добавить метатег в `index.html` или положить файл в корень сайта.
4. Во вкладке «Индексирование» добавьте файл `sitemap.xml`.
5. В файлах `robots.txt` и `sitemap.xml` замените `example.ru` на свой домен.

Сайт появится в поиске не сразу: обычно через несколько дней или недель. Сайт также открывается в Яндекс Браузере. Чтобы автошколу находили на Яндекс Картах, отдельно добавьте организацию в Яндекс Бизнес.

## 6. Установка на телефон

- **iPhone:** откройте сайт в Safari, нажмите «Поделиться», затем «На экран Домой». Кнопки «Установить» на iPhone нет.
- **Android:** откройте сайт в Chrome. Появится предложение установить приложение, либо меню, затем «Установить приложение». Яндекс Браузер проверьте на своём телефоне.

## 7. Как будут работать уведомления

Сейчас на сайте есть колокольчик с историей уведомлений. После запуска серверной части те же события будут приходить сообщениями на экран телефона.

| Событие | Кому |
|---|---|
| Инструктор записал на занятие или на экзамен | Ученику |
| Инструктор отменил запись | Ученику |
| За час до занятия (проверка раз в час) | Ученику и инструктору |
| Ученик отменил занятие или изменил адрес | Инструктору |
| Новый ученик выбрал инструктора | Инструктору |

Как это устроено:

1. Человек нажимает «Включить уведомления». Браузер спрашивает разрешение, и телефон отправляет серверу свой адрес для сообщений. Сервер хранит его в базе.
2. Когда что-то происходит, сервер сразу отправляет сообщение на телефоны нужного человека.
3. Напоминания сервер отправляет раз в час, ровно в 00 минут по московскому времени. В этот момент он берёт из базы занятия, которые начнутся ровно через час, и отправляет напоминания ученику и инструктору. Для этого один раз настройте расписание: `crontab -e` и строка `0 * * * * TZ=Europe/Moscow /usr/bin/node /opt/omega/remind.js`.
4. Если уведомления выключены на телефоне, сообщение не придёт, но запись останется в колокольчике на сайте.

Ограничения: на Android всё работает после «Разрешить», на iPhone только если сайт добавлен на главный экран (iOS 16.4 и новее).

## 8. Важно

**Серверная часть ещё не готова.** Сейчас сайт хранит аккаунты, записи и расписание в браузере каждого человека. Регистрация ученика на его телефоне не дойдёт до Елены на её телефоне. Пока нет серверной части (база данных, вход, уведомления), настоящих учеников принимать нельзя. Подробное описание для разработчика лежит в `TZ-server.md`.

Пароли хранятся не открытым текстом, но это не заменяет серверную защиту. Для настоящей работы вход должен проверять сервер.

**Закон.** Имена и телефоны учеников это персональные данные: сервер должен быть в России, нужны политика конфиденциальности и галочка согласия при регистрации. По уведомлению Роскомнадзора проконсультируйтесь с юристом.
